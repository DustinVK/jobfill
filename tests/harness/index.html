jobfill test harness

Local pages reproducing the hard autofill mechanics with zero ATS dependence. To drive them manually: open a page, then paste the contents of dist-harness/content.harness.js into the console (the e2e injects it the same way) — the overlay appears with the sample vault behind it.

  • blank page — overlay smoke test
  • plain application form — labels, radios, select, deny-listed password
  • React 18 controlled form — native-setter + state mirror
  • late-mounting SPA form — 600 ms delayed render
  • shadow DOM form — open shadow root
  • same-origin iframe form
  • dropzone upload — hidden-input + drop-only patterns
  • options app — in-memory adapters, localStorage persistence
