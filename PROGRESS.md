## Decisions

- **2026-09-06 00:20 — Overnight plan lives at repo root, not `docs/`.** The seed commit put
  `OVERNIGHT_PLAN.md` at the root; `docs/` is empty. Treated the root file as the active work order.
- **2026-09-06 00:22 — Hand-written `browser` ambient types** (`src/shared/adapters/browser-api.d.ts`)
  instead of `@types/firefox-webext-browser`. Keeps the dependency set to the approved list and
  documents exactly which browser surface the extension depends on — anything undeclared is unused.
- **2026-09-06 00:23 — Idempotence guard on `globalThis`, not a module variable.** SPEC §8.4 says
  "module-scope flag", but each `scripting.executeScript` runs the bundle in a *fresh lexical scope*
  within the same content-script global, so a module variable would not survive re-injection. The
  guard lives at `globalThis.__jobfillSession`, satisfying the intent (re-invoke = re-scan, one overlay).
- **2026-09-06 00:24 — New devDependency `jsdom`** (justification per CLAUDE.md): classifier corpus
  fixtures are HTML fragments (SPEC §11.1), so unit-testing `label.ts`/`classify.ts` needs a DOM.
  Opt-in per file via `// @vitest-environment jsdom`; vitest 5 dropped `environmentMatchGlobs`.
- **2026-09-06 00:24 — New devDependency `globals` + `@eslint/js`**: required peers for a flat
  eslint config. No runtime footprint.
- **2026-09-06 00:26 — `npm run lint:ext` is a wrapper script, not raw `web-ext lint`.**
  `--warnings-as-errors` would fail on four warnings that are correct as-is (see below), and plain
  `web-ext lint` exits 0 on any warning. `scripts/check-ext-lint.mjs` fails on every error *and* on
  any warning whose code is not in a documented allowlist, so a *new* warning breaks the build.
- **2026-09-06 00:26 — Harness bundles build to `dist-harness/`, never `dist/`.** Keeps `dist/`
  exactly what ships, so `check:local-only` and `web-ext lint` grade the real artifact.
- **2026-09-06 00:27 — The e2e test hook (`window.__jobfillHarness`) lives only in
  `src/content/harness-entry.ts`.** The production bundle's shadow root stays genuinely closed with
  no page-reachable reference (SPEC §7.9); only the never-shipped harness entry exposes one.
- **2026-09-06 00:28 — Prettier does not format Markdown.** It reflowed SPEC.md, which CLAUDE.md
  forbids editing. `*.md` and `.claude/` are in `.prettierignore`; both files were restored.

## Deviations

- **Accepted `web-ext lint` warnings (4).** `KEY_FIREFOX_UNSUPPORTED_BY_MIN_VERSION` and its Android
  twin fire because SPEC §8.2 pins `strict_min_version: 128.0` while also requiring
  `gecko.data_collection_permissions` (mandatory for new AMO submissions since Nov 2025; the key
  landed in FF 140 / Android 142). Older Firefox ignores the key and AMO requires it, so the manifest
  stays as specced. `UNSAFE_VAR_ASSIGNMENT` ×2 comes from Preact's own `dangerouslySetInnerHTML`
  support path in the vendored library; jobfill never passes that prop.
